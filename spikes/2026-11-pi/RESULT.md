# Проба pi с локальной моделью — результат

Дата: 2026-11-14. Пакет: `@earendil-works/pi-coding-agent` **1.5.2** (зафиксирован в `package.json`), Node 24.5.

## Вывод

**pi годится.** С моделью `qwen3.6-fp8` — 15 из 15 прогонов с верным инструментом и аргументами; всё, на что
опирается этап 3, выполнимо. Решение «pi или запасной путь» — за Алексеем.

## Вызов инструментов (5 реплик × 3 прогона, новая сессия на каждый)

| Модель | Результат | Что не так |
|---|---|---|
| `qwen3.6-fp8` | 15/15 | — |
| `qwen3.6-fp8-noreason` | 15/15 | — |
| `qwen3.8-27b-noreason` | 13/15 | на «Удали акт …» дважды сначала нашла акт и переспросила текстом, не вызвав `delete_act` |
| `qwen3.8-27b` | не годится | на «Привет, что ты умеешь?» трижды вернула пустой ответ; на «Удали…» один раз пустой ответ |

Проект предполагал `qwen3.8-27b` моделью диалога — по пробе её надо заменить на
`qwen3.6-fp8` (или `-noreason`: тот же результат, ответ быстрее).

## Что подтверждено в SDK (точные имена)

- **Встроенные инструменты выключаются**: `createAgentSession({ noTools: "builtin" })`. `session.getActiveToolNames()`
  вернул только `["find_acts", "delete_act"]`; на просьбу «выполни ls и прочитай package.json» модель ответила, что
  таких инструментов у неё нет, вызовов не было.
- **Свои инструменты**: опция `customTools: ToolDefinition[]`, описание через `defineTool({ name, label, description,
  parameters: Type.Object(...), execute(toolCallId, params) })`, схемы — пакет `typebox`. Расширения не нужны.
- **Свой каталог агента**: `agentDir` + `ModelRuntime.create({ authPath, modelsPath })`; `~/.pi/agent` не используется.
- **Хаб**: `models.json`, провайдер с `api: "openai-completions"`, `apiKey: "!~/.local/bin/neuraldeep-hub-key"`
  (команда, ключ на диск не пишется), `compat.supportsDeveloperRole: false`.
- **Автозагрузка отключается** передачей своего `resourceLoader` с пустыми `getExtensions/getSkills/getPrompts/
  getAgentsFiles`; системная подсказка — `getSystemPrompt()`.
- **Сессия на диске**: `SessionManager.create(cwd, sessionDir)`, продолжение после перезапуска —
  `SessionManager.open(session.sessionFile, sessionDir)`. Проверено: вторая сессия помнит сказанное в первой.
- **Служебное сообщение от бота**: `session.sendCustomMessage({ customType, content, display: false }, { triggerTurn })`.
  Проверено: модель пересказала содержимое такого сообщения в следующем ответе.

## Наблюдения для этапа 3

- На «Есть акты по обратной засыпке?» модель ищет `text: "обратная засыпка"` — в именительном падеже. В реестре
  «обратной засыпки», подстрочный поиск такое не найдёт. Поиск по тексту в ядре должен сравнивать по основам слов
  (или по каждому слову без окончания).
- Модель охотно отвечает таблицами Markdown; в Telegram их надо запретить подсказкой.
- Подтверждение удаления модель иногда спрашивает текстом сама. Кнопка от бота всё равно обязательна: полагаться
  на модель нельзя.
